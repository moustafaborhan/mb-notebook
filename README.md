# MB Notebook

A Word-style notebook (OneNote-like sections and pages) for Windows and Android.

- **Sign in:** Google account only.
- **Storage:** your Google Drive folder `MBorhan-Cloud_Word`. Each section is a folder, each page is a Google Doc.
- **Sync:** edits save to the Google Doc a couple of seconds after you stop typing; other devices update within about 15 seconds.
- **Offline:** the app opens without internet and uploads your edits when you're back online.
- **App:** install from Chrome (Android) or Edge (Windows), or use the portable `MB Notebook.exe`.

Open: https://moustafaborhan.github.io/mb-notebook/

Settings live in `config.js` (Google OAuth Client ID and the Drive folder ID). The Client ID is public by design; no secrets are stored here.
